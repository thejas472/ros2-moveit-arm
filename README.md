# ROS 2 MoveIt 2 Robotic Arm

A 4-DOF robotic arm simulation built with **ROS 2 Humble** and **MoveIt 2** for motion planning, inverse kinematics, and trajectory execution. The project includes a custom URDF, `ros2_control` integration, RViz visualization, and Arduino-based hardware control.

---

## Features

- 4-DOF Robotic Arm
- ROS 2 Humble
- MoveIt 2 Motion Planning
- Inverse Kinematics (IK)
- Trajectory Planning & Execution
- ros2_control Integration
- Joint Trajectory Controller
- RViz Visualization
- Arduino Servo Control
